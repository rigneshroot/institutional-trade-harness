# Datasets Directory

This directory contains experimental datasets used for testing and validating the **Institutional Trade Harness**.

## Technical Disclaimer
* **Data Status:** The datasets stored in this directory (including `sample_prices.csv`) are **synthetic deterministic SPY-like price sequences** designed with an artificial correction sell-off anomaly.
* **Usage:** These sequences are created for software validation, unit testing, and empirical framework execution. They are **not** live trading feeds or exact real-world market assets, and should not be used to infer live trading performance.
